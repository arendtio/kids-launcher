# KidSpace Launcher — Vision

KidSpace is a child-friendly Android home launcher designed for use on a **regular (adult) Android profile**, not a restricted child profile. The adult configures what the child can access; the child sees only a curated, colorful surface with large tap targets.

## Problem

Parents want controlled, beautiful device access for children without relying on Android's limited child profiles. They need a launcher that hides the full system while remaining fully customizable from a protected parent area.

## Goals

- Safe, curated child home screen on a normal user profile
- Large, colorful, chic UI with graphic tiles (never text-only links)
- Fully individualizable child surface (add, remove, reorder)
- Parent mode protected by an English number-word challenge
- Parent tools: browse installed apps, edit child tiles, customize appearance

## Non-Goals (v1)

- Multi-child profiles within the app
- Remote parental controls / cloud sync
- Time limits or usage analytics
- Kiosk / device-owner lockdown (future consideration)
