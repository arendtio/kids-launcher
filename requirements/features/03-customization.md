# Feature: Customization

## User Story

As a parent, I want to personalize the child surface so it feels fun and unique for my child.

## Acceptance Criteria

- [ ] Background image can be set from device gallery
- [ ] Child-friendly **preset backgrounds** are available in a picker
- [ ] Primary, secondary, and accent colors are adjustable
- [ ] Preset color themes are available
- [ ] Changes preview on the child surface immediately after save
- [ ] All child tiles can be removed; parent can add them back anytime

## Preset Backgrounds (v1)

- Sunny Meadow (warm yellow-green gradient)
- Ocean Bubbles (blue-teal gradient)
- Candy Clouds (pink-purple gradient)
- Starry Night (deep blue with stars)
- Rainbow Hills (multi-color soft gradient)
