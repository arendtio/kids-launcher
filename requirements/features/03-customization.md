# Feature: Customization

## User Story

As a parent, I want to personalize the child surface so it feels fun and unique for my child.

## Acceptance Criteria

- [ ] Background image can be set from device gallery (JPEG/PNG)
- [ ] Child-friendly **illustrated vector presets** are available — sharp scenes that recolor with the theme
- [ ] Primary, secondary, and accent colors are adjustable (tints vector preset scenes)
- [ ] Preset color themes are available
- [ ] Changes preview on the child surface immediately after save
- [ ] All child tiles can be removed; parent can add them back anytime

## Preset Backgrounds (v1)

Illustrated vector scenes (Canvas-drawn, infinitely sharp):

- **Sky Meadow** — sun, clouds, rolling hills, flowers
- **Ocean Bubbles** — waves, bubbles, fish
- **Candy Clouds** — fluffy clouds, stars, hearts
- **Starry Night** — moon, stars, silhouette hills
- **Rainbow Hills** — rainbow arc over green hills

Colors follow the selected theme (primary / secondary / accent).
